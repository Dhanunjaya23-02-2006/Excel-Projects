# Data Dictionary

| Column | Description | Data Type |
|---|---|---|
| Call Number | Unique identifier for each customer call | Text |
| Customer ID | Unique identifier for each customer | Text |
| Duration | Duration of the customer call | Number |
| Representative | Call center representative ID | Text |
| Date of Call | Date when the call occurred | Date |
| Purchase Amount | Purchase amount associated with the call | Number |
| Satisfaction Rating | Customer satisfaction score | Decimal |
| FY | Financial year derived from the call date | Number |
| Day of Week | Day extracted from the call date | Text |
| Duration Bucket | Category representing call duration | Text |
| Rating Rounded | Rounded customer satisfaction rating | Number |
| Gender | Gender of the customer | Text |
| Age | Age of the customer | Number |
| City | Customer city | Text |
