# Project Overview

## Customer Call Center Analytics Dashboard

This project analyzes customer call center performance using Microsoft Excel.

The objective of the project is to analyze call activity, purchase amounts,
customer satisfaction, representative performance, customer demographics,
and call trends.

## Objectives

- Analyze total customer calls
- Calculate total purchase amount
- Analyze call trends over time
- Evaluate representative performance
- Analyze customer satisfaction ratings
- Compare male and female callers
- Analyze customer distribution by city
- Identify high-performing representatives
- Build an interactive Excel dashboard

## Tools Used

- Microsoft Excel
- Excel Formulas
- Lookup Functions
- Pivot Tables
- Pivot Charts
- Slicers
- Power Query
- Data Cleaning
- Data Visualization

## Dataset

The project contains 1,000 customer call records.

The data includes:

- Call Number
- Customer ID
- Call Duration
- Representative
- Date of Call
- Purchase Amount
- Satisfaction Rating
- Financial Year
- Day of Week
- Duration Bucket
- Rounded Rating

Customer information includes:

- Customer ID
- Gender
- Age
- City

## Final Deliverable

An interactive Excel dashboard that provides insights into call center
performance and customer behavior.
