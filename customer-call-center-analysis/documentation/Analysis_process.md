# Analysis Process

## Step 1: Data Collection

The customer call center dataset was loaded into Microsoft Excel.

## Step 2: Data Understanding

The dataset was reviewed to understand:

- Number of records
- Column names
- Data types
- Missing values
- Duplicate values
- Customer and call information

## Step 3: Data Cleaning

Power Query was used to prepare and transform the data.

The cleaning process included:

- Checking data types
- Reviewing missing values
- Reviewing duplicate records
- Formatting date columns
- Cleaning text values
- Preparing the dataset for analysis

## Step 4: Feature Engineering

Additional columns were created for analysis, including:

- Financial Year
- Day of Week
- Duration Bucket
- Rounded Satisfaction Rating

## Step 5: Formula Analysis

Excel formulas were used for calculations and analysis.

Examples include:

- SUM
- AVERAGE
- COUNT
- COUNTIF
- COUNTIFS
- SUMIF
- SUMIFS
- IF
- IFS
- IFERROR

## Step 6: Lookup Analysis

Lookup functions were used to work with related customer information.

Functions learned and applied include:

- VLOOKUP
- XLOOKUP
- INDEX
- MATCH

## Step 7: Pivot Table Analysis

Pivot Tables were created to analyze:

- Call trends
- Representative performance
- Customer demographics
- Purchase amounts
- Satisfaction ratings
- Call duration

## Step 8: Data Visualization

Pivot Charts were created to visualize the analysis.

## Step 9: Dashboard Development

The final interactive dashboard was created using:

- KPI Cards
- Pivot Charts
- Pivot Tables
- Slicers
- Conditional Formatting
- Interactive Filters

## Step 10: Business Insights

The dashboard results were analyzed to identify important patterns,
trends, and representative performance.
