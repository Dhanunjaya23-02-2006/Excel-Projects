# Dashboard Guide

## Recommended Layout
```text
STUDENT PERFORMANCE DASHBOARD

[Gender] [Race/Ethnicity] [Parent Education] [Lunch] [Test Preparation]

[Total Students] [Average Marks] [Highest Marks] [Pass %] [Top Performer]

[Average Marks by Subject]   [Gender-wise Performance]
[Parent Education vs Marks]  [Lunch Type vs Marks]
[Test Preparation Impact]    [Pass/Fail Distribution]
[Score Distribution]
```

## Chart Selection
| Analysis | Recommended Chart |
|---|---|
| Average Marks by Subject | Clustered Column |
| Gender-wise Performance | Clustered Column |
| Parent Education vs Marks | Bar/Column |
| Lunch Type vs Marks | Column |
| Test Preparation Impact | Column |
| Pass/Fail Distribution | Donut |
| Score Distribution | Histogram/Column |

## Design
- Keep a clean layout
- Use consistent fonts
- Avoid 3-D charts
- Keep slicers aligned
- Use readable number formats
- Remove unnecessary gridlines
- Avoid overcrowding

## Testing
Test multiple slicer combinations and confirm KPI cards, Pivot Tables, and charts update correctly.
Save the final dashboard screenshot in `screenshots/dashboard.png`.
